# 생태야장 소개 페이지

생태 현장조사 야장 앱 **생태야장**(Play 스토어 `com.biogrideia.field`)을 소개하는 정적 페이지입니다.

- 주소: https://yajang.biogrideia.com/
- 새 주소는 호스팅케이알 DNS의 CNAME 레코드(`yajang` → `cirmax82-beep.github.io`)로 연결됩니다.
- 글과 화면은 발표자료 `생태야장_소개.pdf`에서 가져왔습니다.

## 파일

- `index.html`, `css/style.css`, `js/app.js`(화면 예시 탭)
- `img/screen-*.webp` 앱 화면, `img/plan-*.webp` 도면 그림, `img/og.png` 공유용 그림, `img/qr-play.svg` Play 스토어 QR
